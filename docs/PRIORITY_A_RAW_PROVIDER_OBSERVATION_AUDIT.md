# Priority A raw provider-observation audit

## Purpose

This audit moves beyond matching competition labels and season start years. It reads the latest five archived observation snapshots per provider/resource for Bzzoiro, football-data.org, OpenFootball, OpenLigaDB and LiveScoreFootball, then compares the exact source competition/season IDs, teams and timezone-aware kickoffs for the ten Priority A entries.

## Evidence levels

- **Source ID present:** the provider's own competition and season IDs are recovered from its archived observations.
- **Participant evidence:** distinct home/away teams and fixture identifiers are counted per source competition/season.
- **Exact fixture overlap:** the same country, competition name, home team, away team and UTC kickoff are observed from at least two providers. This is stronger evidence than a shared season start year.
- **Not observed:** no matching row was found in the selected recent snapshots. This is not evidence that a provider lacks that competition.

## Safety

The database transaction is explicitly set to read-only. The audit does not create canonical competitions/seasons, provider links, fixtures, staging records or prediction-ledger rows. It does not approve identity or enable future-fixture routes.

## Output

`reports/provider_independent_catalogue/priority_a_provider_observation_audit/latest.json`

The output is generated by the read-only workflow/manual run using `PROVIDER_DATABASE_URL`. Missing or stale snapshots must be reported as an evidence gap, not interpreted as a negative provider-coverage finding.
